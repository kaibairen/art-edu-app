# P0.1 教师班级归属小补（F-011）

P0 不交付完整班级模块。教师看见哪些学员，由 **字符串精确匹配** 决定：

```
User.classNames[]  ⊇  Student.className
```

不匹配或学员未分班 → 教师读取 404「无法查看」。

## 管理端要能配

- 创建 / 编辑教师账号时编辑 `classNames: string[]`（最多 20）
- 接口：`POST /api/v1/admin/accounts`、`PATCH /api/v1/admin/accounts/{id}`
- 学员表单填写 `className`（如 `创意水彩班`）
- **不要**再提供「分配教师」绑定接口（预研 TeacherStudent 已废弃）

## 教师端消费

- `GET /teacher/students` 按班级过滤
- 无班级或列表为空：展示「请联系管理员分配班级」

演示种子：林老师 `classNames=['创意水彩班']`，小明/小红 `className='创意水彩班'`。
